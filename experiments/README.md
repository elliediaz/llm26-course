# experiments: 회차별 보조 실험

> 원리를 눈으로 확인하는 짧은 완성 코드. 빈칸 없이 바로 실행되고, 옵션으로 조건을 바꿔 결과가 어떻게 달라지는지 봄
> 언제 무엇을 바꿔 볼지는 회차별 실습가이드·워크북과 `tasks/`의 카드에 있음

| 회차 | 파일 | 바꿔 볼 것 | 볼 것 |
|---|---|---|---|
| 1 | `s01/dense_heads.py` | 은닉층 크기·깊이, 활성화(없음 포함), 에폭, 학습률 | 같은 특징 추출부에 출력층만 다른 분류·회귀, 이탈 정확도와 플레이 시간 MAE |
| 1 | `s01/cnn_shapes.py` | 채널, 필터 크기, 패딩, 풀링 유무, MLP 비교 | 층별 모양, 펼친 크기, 합성곱 대 Linear 파라미터 수 |
| 1 | `s01/next_token.py` | 문장, 단계 수, 후보 수, 모델 | 어휘 크기 = 클래스 수, 단계별 1등 확률, 생성 = 분류의 반복 |
| 1 | `s01/score_and_pick.py` | 질의, 기준값, 임베딩 모델 | 점수(연속값) → 고르기(분류), 기준값에 따른 맞힘·무관 거름·놓침 |
| 1 | `s01/ticket_clf.py` | 규제 강도 C, 학습 건수 | category 정확도, priority 분류 대 회귀(정확도·MAE) |
| 2 | `s02/self_attention.py` | 토큰 수, 차원, 마스크 유무, √d 나누기 유무 | 주의 가중치 표, 행 합 1, 행별 엔트로피(쏠림) |
| 2 | `s02/sampling.py` | 문장, 온도·Top-k·Top-p 조합, 뽑는 횟수 | 같은 분포에서 고르는 규칙에 따라 달라지는 서로 다른 토큰 수 |
| 2 | `s02/label_score.py` | 합·평균, 모델 | 생성 없이 라벨 확률로 분류, 짧은 라벨 쏠림 |
| 5 | `s05/chat_template.py` | 모델, 시스템 프롬프트 유무, assistant 차례 표시 유무, 템플릿 있음·없음 생성 | 특수 토큰, 토큰 수, 출력이 끝나는지 |
| 5 | `s05/scoring_rules.py` | 필드 가중치, 비교 방식, 허용 오차, 느슨·엄격 파싱 | 같은 출력의 점수가 규칙 하나로 얼마나 바뀌는지 |
{: widths=7%,24%,34%,35% key=0}

- 작업 폴더(저장소 최상위)에서 실행함: `python experiments/s01/dense_heads.py --act none`
- 결과를 남기고 싶으면 명령과 출력 끝의 숫자를 `results/판단기록_sNN.md`에 적음
