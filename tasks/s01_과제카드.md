# 1회차 과제 카드: 모든 AI 응용은 분류 또는 회귀

> 오늘의 명제: AI를 쓰는 응용은 겉모습이 달라도, 모델의 마지막 출력은 **분류**(정해진 후보 중 하나 고르기) 아니면 **회귀**(숫자 하나 내기)로 귀결됨
> 판정 기준 세 가지: ① 출력층의 크기(후보 수 vs 숫자 1개) ② 손실(교차 엔트로피 vs 평균제곱오차) ③ 지표(정확도·F1 vs MAE·RMSE)

## A. 응용 분해 카드 (필수, 팀 과제, 2회차 전까지)

아래 응용을 팀이 나눠 맡아 빈칸을 채움. "둘 다"도 정답일 수 있으며, 그때는 어느 부분이 분류이고 어느 부분이 회귀인지 적음

| # | 응용 | 입력 | 모델이 마지막에 내는 것 | 분류 / 회귀 | 손실 | 지표 |
|---|---|---|---|---|---|---|
| 1 | 번역기 | 한국어 문장 | | | | |
| 2 | 동영상 추천 | 시청 기록·영상 정보 | | | | |
| 3 | 자율주행 차선 유지 | 카메라 영상 | | | | |
| 4 | 이미지 생성(확산 모델) | 글 설명 + 잡음 그림 | | | | |
| 5 | 음성 비서 | 음성 | | | | |
| 6 | 결제 사기 탐지 | 결제 기록 | | | | |
| 7 | 쇼핑 리뷰 별점 예측 | 리뷰 글 | | | | |

| 9 | 우리 팀 과제(G·L·S 중 가선택 분야) | 문의·상황·질문 | JSON 필드 7개 | 필드마다 | | |

- 제출: 팀 대표가 표를 사진으로 찍어 수업 공지 채널에 올림(2회차 시작 전까지). "가장 의견이 갈린 칸"에 표시하고 이유를 한 줄로 적음
- 2회차 복습 시간에 강사가 의견이 갈린 칸 두세 개를 짚음

## B. '해당 없음'이라는 클래스 만들기 (개인 도전, 10분)

```bash
python src/faq_search.py --queries my_queries.json --threshold 0.5
```

- 기준값을 0.3 · 0.5 · 0.7로 바꿔 가며 "놓친 질문"(정답 FAQ가 있는데 해당 없음)과 "잘못 찾은 질문"(무관 질문인데 FAQ를 고름)의 수를 표로 적음
- 질문: 기준값은 점수(연속값)를 분류로 바꾸는 경계임. 6회차 RAG에서 검색 결과를 몇 개(k) 넣을지, 점수가 낮으면 넣지 않을지 정할 때 이 표가 근거가 됨

## C. 드문 클래스 살리기 (개인 도전, 10분)

- `src/ticket_classifier.py`의 `LogisticRegression(...)`에 `class_weight="balanced"`를 더해 다시 실행함
- 검증 정확도와 macro-F1이 각각 어떻게 바뀌는지 적음. 왜 정확도와 macro-F1이 반대로 움직일 수 있는지 한 줄로 설명함
- 연결: 5회차 문항 유형 할당(K·R·F)도 같은 이유로 비율을 정해 둠

## D. 회귀를 분류로 바꾼 이유 (개인, 5분)

- `results/cls_vs_reg.json`의 두 방식 결과를 보고 답함
  1. 회귀 모델이 "자릿수"는 거의 맞히면서 "정확한 금액"은 거의 못 맞히는 이유
  2. LLM이 숫자를 쓸 때는 어느 쪽에 가까운가(힌트: 1회차 실습 E의 T3, 숫자도 토큰임)
  3. 그렇다면 주휴수당·보증금 증액처럼 정확한 계산이 필요한 일은 어떻게 처리해야 하는가(8회차 Tool과 연결)
