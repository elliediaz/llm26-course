# 7회차 실습 안내 : 내 데이터로 모델 학습시키기(LoRA 샌드박스)

> 실습은 내 GPU 서버의 주피터 노트북 두 개에서 함. 학습은 `notebooks/s07_my_lora.ipynb`, 마지막 40분의 최종 스튜디오는 `notebooks/s07_final_studio.ipynb`. 6회차와 같은 번호의 서버를 씀
> 단계별 설명과 실측값은 워크북(`handouts/07회차_1124/07회차_실습워크북_V5.pdf`)에 있음

## 시작할 때
1. 이 저장소의 `ACCESS.md`(발표 2번 장 오른쪽 QR)에서 내 서버 번호 줄의 '바로 열기'를 누름(주소는 날마다 바뀜)
2. `notebooks` 폴더의 `s07_my_lora.ipynb`를 열고 0단계의 두 셀을 실행함. 6회차에 저장한 솔루션이 올라옴
3. 6회차 결과가 없으면 새 셀에서 `lab.docs_panel()`로 문서를 넣고 `lab.quiz_panel()`로 확인 질문을 적은 뒤 이어 감

## 끝낼 때
- `lab.save_solution(adapter="고른 이름")`으로 내 솔루션을 저장함(8회차의 출발점)
- `lab.pack()` 실행 → `my_results_*.zip` 내려받기
- 스튜디오 S9에서 띄운 웹 화면 · API는 `lab.stop_api()`로 끔(주소를 아는 사람은 누구나 열 수 있음)

## 8회차에서 쓰는 방법

```python
import lab
lab.load_solution()                                  # 모델 · 문서 · Adapter 가 그대로 올라옴
answer = lab.ask("질문", show=False)["answer"]         # 답 받기
r = lab.bot("질문", show=False)                        # 완성 모습 한 턴 : r["answer"] · r["state"] · r["image"]["path"]
```

- 스튜디오에서 만든 `my_bot` 함수와 FastAPI 앱(`/api/chat` · `/api/asr` · `/api/info`)은 9 · 10회차 서비스의 출발점임. 스튜디오 노트북을 다시 열어 S0 → S7 → S9 순서로 실행하면 같은 주소 구조로 다시 띄워짐
