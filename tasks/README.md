# tasks: 과제 카드와 해보기

> 과제 카드: 팀·개인에게 던지는 주제. 정해진 정답 코드를 따라 치는 것이 아니라, 주어진 도구로 직접 답을 찾고 근거를 기록함
> 해보기: 기본 코드의 값·대상·하이퍼파라미터를 바꿔 결과를 비교하는 연습. 기본 코드·데이터·힌트가 모두 저장소 안에 있음
> 결과는 `results/` 또는 카드에 적힌 파일에 남김. 예시 답은 강사·TA만 가짐

| 회차 | 카드 | 형태 | 시점 |
|---|---|---|---|
| 1 | `s01_해보기.md` A~C(Dense·CNN·LSTM 조정) | 개인·짝 | 2교시 실습 B 뒤 |
| 1 | 〃 D~G(FAQ 검색기, 티켓 분류기, 회귀 vs 분류, 노트북) | 개인 | 3교시 해보기·귀가 후 |
| 1 | `s01_과제카드.md` A 응용 분해 | 팀 과제 | 2회차 전까지 |
| 1 | 〃 B~E | 개인 도전·복습 | 실습이 일찍 끝난 사람, 귀가 후 |
| 2 | `s02_해보기.md` ① A~C(MiniGPT 조정·내 문장 토큰·내 문장 Self-Attention) | 개인 | 2교시 사전학습·정렬 설명 뒤 |
| 2 | 〃 ② D·E(팀 생성 설정 확정, KV Cache 손계산), F(LLM을 분류기로) | 팀·개인 | 3교시 실습 3 뒤 |
| 2 | 〃 G~I(10회 반복, 템플릿 유무, 노트북 복습) | 개인 | 귀가 후 |
| 5 | `s05_사건카드.md` 사건 1~7(템플릿·형식 강제·재현성·문제 입력·시험지·채점 규칙·Baseline) | 팀(실행 담당 1명 + 문항·해석) | 실습 전체 |

## 기록 원칙

- 숫자 하나에는 근거 한 줄(어떤 명령으로, 어떤 조건에서 쟀는가)
- 한 번에 하나만 바꿔서 잼. 두 가지를 동시에 바꾸면 무엇의 효과인지 알 수 없음
- 실존 개인정보·실제 근로 정보는 쓰지 않음(데이터는 해외 서버로 전송됨)
