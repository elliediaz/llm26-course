# 6회차 실습 안내 : 내 문서로 답하는 챗봇(RAG 샌드박스)

> 실습은 내 GPU 서버의 주피터 노트북 `notebooks/s06_my_rag.ipynb`에서 함. 터미널에 명령을 치지 않음
> 단계별 설명과 실측값은 워크북(`handouts/06회차_1123/06회차_실습워크북_V5.pdf`)에 있음

## 시작할 때
1. 이 저장소의 `ACCESS.md`(발표 2번 장 오른쪽 QR)에서 강사가 정해 준 서버 번호 줄의 '바로 열기'를 누름. 비밀번호를 물으면 같은 줄의 비밀번호를 넣음
2. 왼쪽 파일 창의 `notebooks` 폴더에서 `s06_my_rag.ipynb`를 엶
3. 셀을 위에서 아래로 한 번씩 실행함(`Shift + Enter`). 조절판이 나오면 값을 바꾸고 단추를 누름

## 단계

| 단계 | 구분 | 하는 일 | 조절판 |
|---|---|---|---|
| 0 · 1 | 필수 | 시작, 모델 올리기 | `lab.start(6)` · `lab.model_panel()` |
| 2 | 필수 | 내 재료 넣기(직접 쓰기 · 위키백과 · 예제 재료 · 파일) | `lab.docs_panel()` |
| 3 | 필수 | 내 확인 질문 만들고 문서 없이 · 문서 붙여 풀기 | `lab.quiz_panel()` |
| 4 | 선택 | 자르기 실험(방식 · 청크 크기 · 중첩) | `lab.chunk_panel()` |
| 5 | 선택 | 의미 지도 | `lab.map_panel()` |
| 6 | 선택 | 찾기 실험(가져올 청크 수 · 키워드 비중) | `lab.search_panel()` |
| 7 | 필수 | 문서를 붙여 답하기(전후 답을 나란히) | `lab.ask_panel()` |
| 8 | 필수 | 설정 실험(설정 하나를 여러 값으로) | `lab.experiment_panel()` |
| 9 | 선택 | 모델 비교(모델을 하나 더 올려 비교) | `lab.arena_panel()` |
| 10 · 11 | 필수 | 내 챗봇, 솔루션 저장, 판단 기록, 결과 묶기 | `lab.chat()` · `lab.save_solution()` · `lab.note_panel()` · `lab.pack()` |
| 12 | 더 해 보기 | 벡터DB(Chroma)에 직접 넣고 찾기 | `lab.chunks()` · `lab.embed()` · `lab.llm()` |

- 선택 단계 4 · 5 · 6 · 9 가운데 둘 이상을 함. 12단계와 노트북 맨 아래 '더 해 보기 A~H'(문장 쌍 유사도, 유사도 그림, 질문 바꿔 묻기, 키워드 비중, 직접 짠 검색, 설정 실험 코드, 문서에 없는 질문, 스스로 점검)는 필수 단계를 마친 뒤 해 봄
- 규칙 : 한 번에 하나만 바꿈. 실행 전에 예측을 적음
- 재료 규칙 : 본인과 타인의 실제 개인정보, 외부 반출이 금지된 자료(AIHub 데이터 등)를 넣지 않음

## 끝낼 때
- `lab.save_solution()`으로 내 솔루션을 저장함(7회차의 출발점)
- `lab.pack()` 실행 → 왼쪽 파일 창의 `my_results_*.zip`을 오른쪽 단추 → Download

## 조절판 없이 직접 부르기

```python
lab.ask("질문", k=2)                         # 한 건 묻기
lab.run_quiz(rag=True)                       # 확인 질문 전체 풀기
lab.experiment("size", [200, 400, 800])      # 청크 크기 실험
lab.load("Qwen/Qwen3-8B"); lab.arena("질문")  # 모델 추가 후 비교
lab.board()                                  # 내 실험 기록표
lab.chunks(); lab.embed("글"); lab.llm("입력 글")   # 12단계에서 쓰는 함수
```
