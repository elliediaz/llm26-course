## 해보기 ① (19:30~19:48)

### A. 유저 이탈 예측기 조정하기 (Dense, 10분)

- 기본 코드: `src/nn_dense.py` · 데이터: `data/G/churn.csv`(가상 RPG 유저 2만 명, 열 설명은 `data/G/README.md`)
- 기본 결과(개인 CPU 서버, 한 번 약 10초): 분류 정확도 0.83(기준선 0.72), 재현율 0.56 / 회귀 평균 오차 19분(기준선 40분)

| 바꿔 볼 것 | 명령 예 | 생각해 볼 질문 |
|---|---|---|
| 층 크기·깊이 | `--hidden 8` / `--hidden 256 128 64` | 크게 하면 무조건 좋아지나? 분류와 회귀 중 어느 쪽이 더 민감한가 |
| 학습률 | `--lr 0.0001` / `--lr 0.05` | 손실이 줄어드는 속도가 어떻게 달라지나 |
| 에폭 | `--epochs 3` / `--epochs 40` | 시험 정확도가 어디서 멈추나 |
| 판정 기준값 | `--task cls --threshold 0.3` / `--threshold 0.7` | 정확도·재현율·정밀도가 각각 어느 쪽으로 움직이나 |
| 입력 열 빼기 | `--task cls --drop last_login_gap login_days_14` | 어떤 열이 이탈 예측에 가장 중요한가 |

- 힌트 1: 이탈 유저가 28%라 "모두 유지"로 찍어도 0.72가 나옴. 정확도만 보지 말고 재현율(이탈 유저 중 몇 %를 찾았나)도 볼 것
- 힌트 2: 층을 키워도 분류 정확도가 0.83 근처에서 멈춘다면, 모델이 아니라 **입력에 담긴 정보**가 한계일 수 있음. 열을 빼 보면 어느 열이 그 정보를 들고 있는지 보임
- 힌트 3: 기준값은 다시 학습하지 않고 판정만 바꿈. 출력 끝의 "기준값을 바꾸면" 표가 같은 모델의 여섯 기준값 결과임
- 도전: `src/nn_dense.py`의 `DenseNet` 층 사이에 `nn.BatchNorm1d(h)`를 넣어 보기

### B. 옷 사진 분류기 조정하기 (CNN, 10분)

- 기본 코드: `src/nn_cnn.py` · 데이터: `data/common/fashion_mnist/`(Zalando Fashion-MNIST, MIT)
- 기본 결과(개인 CPU 서버, 2에폭, 약 15초): MLP 0.84, CNN 0.88. CNN이 가장 많이 헷갈리는 쌍은 셔츠→티셔츠
- 실습 B에서 친 따라 치기 T2(`typing/s01/t2_cnn_shapes.py`)의 모양표를 옆에 띄워 두고 바꾸면 좋음

| 바꿔 볼 것 | 명령 예 | 생각해 볼 질문 |
|---|---|---|
| 필터 수 | `--model cnn --channels 8 16` / `--channels 32 64` | 파라미터·시간·정확도가 어떻게 바뀌나 |
| 에폭 | `--model cnn --epochs 5` | 셔츠↔티셔츠 혼동이 줄어드나 |
| 드롭아웃 | `--model cnn --dropout 0.3 --epochs 5` | 학습 손실과 시험 정확도의 차이 |
| 대상 바꾸기 | `--target group` | 10종 → 4묶음(상의·하의/원피스·신발·가방)으로 바꾸면 정확도는? 왜? |
| 데이터 줄이기 | `--limit 6000` | 데이터가 10분의 1이면 MLP와 CNN 중 누가 더 손해를 보나 |

- 힌트: `results/fig/nn_cnn_pred.png`(틀린 사진은 빨간 글씨)와 `results/fig/nn_cnn_maps.png`(필터마다 반응하는 무늬)를 함께 볼 것
- 도전: `CNN` 클래스에 세 번째 합성곱 층을 넣어 보기. 펼치기 크기(`c2 * 7 * 7`)를 어떻게 고쳐야 하나

### C. 접속자 예측에서 기준선 이기기 (LSTM 회귀, 선택, 10분)

- 기본 코드: `python src/nn_rnn.py --task ccu` · 데이터: `data/G/ccu_hourly.csv`(가상 RPG 2026년 시간별 동시 접속자, 수요일 06~08시 점검으로 0명)
- 기준선: "어제 같은 시각 값으로 찍기"의 평균 오차 약 1,850명. **기본 설정(5에폭)의 LSTM은 기준선보다 못함(약 2,170명)**
- 목표: 설정만 바꿔서 기준선을 이기기. 이긴 설정과 오차를 기록표에(한 번 5~10초)

| 바꿔 볼 것 | 명령 예 |
|---|---|
| 에폭 | `--task ccu --cell lstm --epochs 15` |
| 입력 창 길이 | `--task ccu --window 24` / `--window 168`(1주일) |
| 상태 크기 | `--task ccu --hidden 32` / `--hidden 128` |
| 구조 | `--task ccu --cell rnn`과 `--cell lstm` 비교 |

- 힌트: 같은 시각·같은 요일 패턴이 강한 데이터임. 창을 늘리면 볼 수 있는 정보는 늘지만 학습해야 할 것도 늘어남
- 생각해 볼 것: 감성 분류(실습 C)와 접속자 예측에서 바뀐 것은 데이터와 마지막 층·손실뿐임
