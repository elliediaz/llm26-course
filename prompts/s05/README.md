# 5회차 덧붙일 규칙 파일

`benchmark.py --prompt`, `sweep.py prompt`, `probe.py --compare`에 넣어 시스템 프롬프트 끝에 붙임

| 파일 | 노리는 문제 |
|---|---|
| `주입방어.txt` | 문의 안의 지시를 따르는 프롬프트 주입 |
| `형식엄수.txt` | 표·설명·코드 펜스를 붙여 JSON이 깨지는 문제, 두 문의가 섞인 경우 |
| `모르면_비움.txt` | 없는 값을 지어내는 문제, 무관 질문 |

- 팀 규칙은 이 폴더에 새 파일(예: `우리팀_v1.txt`)로 만들고, 고칠 때마다 이름을 바꿔 남김(`우리팀_v2.txt`). 어떤 줄이 점수를 바꿨는지 나중에 비교할 수 있음
- 규칙을 늘릴수록 입력 토큰과 지연이 늘어남. 통과율과 점수, 지연을 같이 봄
