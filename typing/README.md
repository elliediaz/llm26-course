## 실습 코드 세 종류

| 종류 | 위치 | 학생이 하는 일 | 예 |

| 단순 실행 | `src/` | 완성된 스크립트를 실행하고 결과 숫자·그림을 해석 | `faq_search.py`, `cls_vs_reg.py`, `benchmark.py` |
| 과제·해보기 | `tasks/` | 값·대상·하이퍼파라미터를 바꿔 보고 결과를 기록, 팀 주제 풀기 | 기준선 이기기, 응용 분해 카드 |
