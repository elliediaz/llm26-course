# S 도메인 데이터: 가상 스포츠 기록실 2026(추출형)

| 항목 | 내용 |
|---|---|
| 과제 | 가상 리그 기록실에 들어온 질문 → 답변 JSON(리그·대상·지표·값·기준일·답 가능 여부) |
| 타입 | **추출형** : 채점 가중치 10 중 6이 값(value)과 답 가능 여부(answerable). 모르는 것을 지어내지 않는지가 핵심 |
| 리그 | 한빛프로야구(8구단, 정규시즌 84경기), 넥서스리그(가상 e스포츠 10팀, 스프링·서머), 월드 인비테이셔널(16팀 국제 대회) |
| 출처 | 강사 제작 가상 기록 DB(`build/sports_db.json`). 실존 구단·선수·대회와 관계없음 |
| 라이선스 | CC BY 4.0(강사 저작). 학생 저장소·포트폴리오에 넣어도 됨 |
| 기준일 | 2026-11-08(기록실 스냅숏). 월드 인비테이셔널 결승(11/14) 결과는 `corpus_updates/`에만 있음 |
| 생성 | `python data/S/build/make_sports_pkg.py` (시드 고정, 다시 실행해도 같은 결과) |
| 개인정보 | 없음. 선수 이름·닉네임은 모두 가상 |

## 파일

| 파일 | 회차 | 내용 |
|---|---|---|
| `schema.json`, `scoring.yaml` | 5~7 | 출력 JSON 형식, 필드별 채점 규칙 |
| `test_seed.json` | 5 | 강사 시드 10건(K4·R3·F3) |
| `team_item_template.json` | 5 | 팀 추가 20건 양식(K8·R7·F5)과 작성 규칙 |
| `test_dataset.json` | 5~7 | `benchmark.py` 입력. 처음에는 시드 10건, 5회차에 팀 20건을 합쳐 30건 |
| `corpus/*.md`, `corpus_manifest.json` | 6 | 기록 문서 66건(리그 안내 3, 시즌·대회 6, 개인 기록 순위 1, 구단 18, 선수 34, 게임 소개 1, 기록실 규약 3) |
| `corpus_updates/` | 6 | 기준일 뒤에 나온 결승 결과 문서. 인덱스에 넣기 전후로 같은 질문의 답이 바뀌는지 봄 |
| `train_seed.jsonl` | 7 | 학습 시드 174건(학습용 구단·선수, 평가와 다른 문장 틀) |
| `tools_spec.md` | 8~10 | Tool 후보(순위표·선수 기록 조회, 계산기, 약칭 정리) |

## 문항 유형

| 유형 | 내용 | 예 |
|---|---|---|
| K 지식형 | 기록 문서를 봐야 답이 나옴 | 정규시즌 최종 순위, 선수 홈런 수, 스플릿 우승팀 |
| R 추론형 | 질문 안의 숫자로 계산함 | 승률, 게임차, 타율, 평균자책점, 시리즈 결과, KDA |
| F 판단형 | 기록실 규약을 알아야 맞힘 | 기준일 뒤 결과, 연봉·이적 같은 비공개 정보, 예측, 없는 시즌, 리그가 겹치는 약칭('비룡') |

## 팀 문항의 정답 만들기

```bash
python data/S/build/s_rules.py winrate --w 43 --l 40        # 0.518
python data/S/build/s_rules.py series --scores 3:2 1:4 6:5  # 2:1
python data/S/build/s_rules.py era --er 41 --ip 160.1       # 2.30
```

- K 문항은 `corpus/`에서 값을 찾아 적고, 그 문서 id를 `gold_doc_ids`에 넣음
- 표기는 `corpus/policy_format.md`를 따름(순위 '3위', 승률 '0.615', 홈런 '31개', 시리즈 '3:1')
- 답하지 않아야 하는 질문은 `answerable: false`, `value`·`as_of`는 null

## 평가셋과 학습셋 분리
- 구단·선수를 평가용(야구 b01~b04, e스포츠 e01~e05)과 학습용(b05~b08, e06~e10)으로 나누고, 문장 틀도 따로 씀
- `build_train_data.py`가 입력 문장 유사도(문자 3-gram 자카드)로 한 번 더 검사함

## 알아 둘 점
- 정규시즌 1위 팀이 우승하지 못했고(한빛시리즈는 2위 팀이 이김), 월드 인비테이셔널 결승은 하위 시드가 이김. 모델이 '그럴듯한 답'을 고르면 틀리게 짜 두었음
- 5월 말 순위처럼 승률이 같은 팀이 있음. 순위는 상대 전적으로 정했으며 `corpus/league_hpb.md`에 방식이 있음
- 시리즈 결과는 물어본 팀 기준이라, 진 팀을 물으면 문서의 '4:3'이 '3:4'가 됨
