# 정산 JSON 작성 규약(이 과정의 채점 기준)

- 금액은 원 단위 정수로 쓰고, 계산 중 생긴 원 미만은 버림
- 근무 시간·시급·사업장 규모(가산수당이 걸리는 경우) 중 하나라도 알 수 없으면 issue는 판단불가, 수치 필드는 모두 null
- 쟁점이 여럿이면 최저임금미달 > 주휴미지급 > 가산미지급 순서로 하나만 고름. unpaid_krw에는 모든 미지급액을 합침
- law_article은 대표 쟁점의 조문 하나: 최저임금미달 = 최저임금법 제6조, 주휴미지급 = 근로기준법 제55조, 가산미지급 = 근로기준법 제56조. 정상지급·판단불가는 null
- 법률 자문이 아니며, 실제 사안은 고용노동부 상담(국번 없이 1350)으로 확인함
